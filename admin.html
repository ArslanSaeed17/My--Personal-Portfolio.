03. Save Your Changes

Changes here only live in this browser tab until you export the file. When you're done adding/editing/deleting:

  1. Click Download updated index.html above.
  2. Replace the existing index.html file at the root of your project with the downloaded one.
  3. If you uploaded any images manually to /assets, make sure they're included too.
  4. Commit & push to GitHub — Vercel will redeploy automatically. The new category filter tabs on the live site update themselves based on whatever categories exist in the data.

Data didn't load automatically? Load it manually

This happens if you open this file directly (file://...) instead of through a server — browsers block that kind of local file loading. Paste the full contents of your current index.html below and click Load, or just try this page on your deployed site instead, where it works automatically.

04. Favicon

The site favicon is a set of static image files in /assets (favicon.ico, favicon-16x16.png, favicon-32x32.png, favicon-48x48.png, apple-touch-icon.png, android-chrome-192x192.png, android-chrome-512x512.png) referenced from index.html's <head>. To change it later, generate a new set with the same filenames and sizes and drop them into /assets — no HTML changes needed.
